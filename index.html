07 / Calculation notes

Q = (V / 1,000,000) / t
Aᵢ = π(Dᵢ / 1,000)² / 4
Vᵢc = Q / Aᵢ
VᵢB = √[2g(h* − hᵢ) / 1,000]
hL,ᵢ = |Htotal,1 − Htotal,ᵢ|

Assumption: horizontal duct, so elevation head is unchanged. Total head is calculated as static head + velocity head. If your apparatus uses a different reference/elevation convention, we can adapt the equations.
